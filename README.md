## Open CV  

- 컴퓨터 비전: 컴퓨터를 사용하여 이미지나 비디오에서 유용한 정보를 추출하는 기술.
- 영상처리 : 입력된 영상을 목적을 위해 처리하는 기술 (예: 노이즈 제거, 이미지 향상, 색상 조정 등)
- 고수준 영상처리 : 영상 분할, 영상표현, 영상인식, 영상이해 등  

- 영상 처리 관련 필요 지식 : 영상처리, 컴퓨터 비전, 컴퓨터 그래픽스, 행렬, 미분, C++, 선형대수, 기하학 등등 

- 영상 획득 과정 : 빛 -> 렌즈 -> 센서 -> ADC -> ISP -> 영상
- 영상이란 : 위치 값과 밝기 값을 가진 일정한 수의 화소들의 모임.  

### 양자화, 샘플링 

- 양자화: 제한된 비트수로 화소값을 나타내려 밝기 값을 정수화 시키는 과정
- 샘플링: 연속적인 영상을 일정한 간격으로 나누어 화소로 표현하는 과정  

### 그레이스케일 영상과 트루컬러 영상 

- 그레이스케일 영상: 각 화소가 밝기 정보만을 가지는 영상. 일반적으로 8비트로 표현되어 0부터 255까지의 밝기 값을 가짐.
- 트루컬러 영상: 각 화소가 색상 정보를 가지는 영상. 일반적으로 RGB 형식으로 표현되어 각 채널이 8비트로 표현되어 0부터 255까지의 색상 값을 가짐.  

### 컬러  

- RGB: 빨강, 초록, 파랑의 세 가지 기본 색상으로 표현되는 컬러 모델. 255 *255 *255 = 16777216 가지의 색상을 표현할 수 있음.

- BMP : 비트맵 이미지 파일 형식. 무압축 방식으로 저장되어 이미지 품질이 높지만 파일 크기가 큼.  
- JPG : 손실 압축 방식으로 저장되는 이미지 파일 형식. 파일 크기가 작지만 이미지 품질이 저하될 수 있음.
- PNG : 무손실 압축 방식으로 저장되는 이미지 파일 형식. 투명한 배경을 지원하며 이미지 품질이 유지됨.  
- GIF : 애니메이션을 지원하는 이미지 파일 형식. 256색으로 제한되어 있지만 간단한 애니메이션을 표현할 수 있음.
